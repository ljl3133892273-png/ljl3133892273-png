### 4 个系统可直接在线体验，无需申请

作品集里每个项目都有「访问线上系统」按钮，点开就能用，不用注册、不用等我开权限。

| 系统 | 做什么 | 技术要点 |
| --- | --- | --- |
| **正狮陶瓷 · 数据问数** | 用一句中文问业务数据，自动生成 SQL 并返回结果 | NL2SQL · 元数据召回 · SQL 校验 · 结果回填 |
| **正狮陶瓷 · 知识库问答** | 上传产品手册，回答问题并给出来源引用 | 稠密 + BM25 混合检索 · 引用溯源 |
| **电商智能客服** | 意图识别 → 澄清 → 知识检索 → 转人工的完整闭环 | 领域驱动分层 · 对话状态管理 |
| **AI 电商运营助手** | 商品文案、主图、短视频素材批量生成 | 异步任务队列 · 多模态生成 |

> 演示环境跑在一台 4 GiB 的云主机上，资源吃紧但都能用。如果某个入口点不开，多半是正在重启，等十几秒再试。
